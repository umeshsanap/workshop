# FutureBright AI Workshop — Frontend

Production frontend for the workshop website.

## Setup

```bash
npm install
```

## Develop

```bash
npm run dev
```

Runs at [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
```

Output is in `dist/`. Serve that folder with any static host (e.g. Netlify, Vercel, GitHub Pages).

## Assets

- Put logo and media in `public/media/` (e.g. `public/media/Logo.jpeg`, `public/media/video-01.mp4`).
